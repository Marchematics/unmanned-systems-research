# 空天地无人系统协同控制团队网站

静态网站，直接打开 `index.html` 预览，通过 GitHub Pages 发布。团队介绍和论文清单依据团队演示材料整理；论文的作者、期刊、年份及 DOI 参考 OpenAlex、Crossref、期刊出版社与高校论文资料库核对。演示材料中的重复论文已去重；`data/publications.json` 保存所列论文的元数据。

页面编辑直接修改 `index.html`；样式和脚本的源文件为 `style.css`、`script.js`。修改样式或脚本后，在本目录运行 `python3 update_assets.py`，生成带内容指纹的资源文件并更新页面引用，以避免浏览器混用新旧文件。图片来自团队提供的演示材料。后续更新请团队核对成员信息、成果及图片的公开授权。

论文配图来源和图号记录在 `data/publications.json`，开放许可的图在页面标注相应许可；EMSF-Net 图片取自团队本地论文稿。未经核实的图不使用占位配图；新增图片前应先检查原文的图版许可及是否含第三方内容。

页眉的学校徽志来自 [学校章程](https://news.zua.edu.cn/info/1011/7381.htm)，学院标识来自 [电子信息学院形象标识页面](https://dzxxxy.zua.edu.cn/xygk/xxbs.htm)。页面以 CSS 展示学院标识中的徽志部分，保留原始文件。

`people/` 为主页已列出的团队负责人与方向负责人提供个人页面。简介依据学校公开的导师简历和学院硕导介绍整理；刘兆瑜导师简历正文未列出详细履历，相关信息以学院公开页面及团队演示材料为准。论文仅列出已核对的团队成果，并链接 DOI。

主页轮播展示团队演示材料中的设备与交流照片，支持自动播放、暂停和手动切换；用户启用减少动态效果时默认停止自动播放。团队动态链接至学院原始报道，标题和日期依据原文整理。
